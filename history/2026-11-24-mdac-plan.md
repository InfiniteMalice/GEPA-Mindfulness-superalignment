Audited baseline: `ab0a1a9`. GitHub searches found no open PR clearly corresponding
to this series. The recently merged metacognitive stack ending at #848 is useful
prior work. The milestone numbers below are plan identifiers.

## Per-PR verification

Pin the baseline, inspect neighboring interfaces, verify the cited source methods for
the milestone, and record the hypothesis, assumptions, and direct versus adapted
or exploratory use. Add deterministic positive and negative tests before product
changes. Include a config example, opt-in coverage, integration tests, and optional
model-backed coverage. Run targeted suites plus affected existing regressions,
repository Ruff, Black and CI mypy checks, complete offline tests, package build
and installed-wheel smoke. Record migrations, actual results, and limitations.

Request independent review and address actionable conversation and inline comments.
Verify fresh CI and review on the head proposed for merge. Merge in dependency
order and verify the recorded merge before proceeding to a dependent PR.

## Initial implementation boundaries

Use Python 3.10-compatible standard-library records for PR 1. Favor stable
string mechanism IDs, versioned strict serialization, immutable evidence tuples,
and optional measurements over shadow changes to case or optimizer schemas.
Treat resolution status as independent of each hypothesis's evidentiary state.
Keep diagnostic-only imports free of model dependencies. Verify preservation of
existing evidence and case records when the extension is disabled.

The maintainer approved the plan and directed implementation on 2026-11-24.
This series uses the documented fallback for the unavailable repo-quality-gate skill.
