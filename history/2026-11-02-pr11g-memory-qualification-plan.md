## Design and alternatives

Native reproduction requires separately configured trained artifacts, Python/CUDA runtime,
raw-source admission and compute authority that are absent. A mock or text cache would not
reproduce query-conditioned latent memory. This stage instead registers the checked primary
method and publishes a bounded qualification/Study F protocol using existing evidence memory,
workspace retrieval, ablation plans and independent audit contracts. No backend, extra,
automatic download, execution callback, runtime permission or optimizer path is added.

Record the primary v1 identity, date, license, author-linked pinned code, exact checked
artifact identities and an authored method-note digest. Code and dataset licensing are
distinct. Document observed Python-version incompatibility, checkpoint/config identities,
source-to-embedding binding and current access checks, supervised/agentic distinctions,
matched baselines, negative controls and unrun effectiveness. Source metadata changes cannot
upgrade a recommendation's status or create a supported model capability.
