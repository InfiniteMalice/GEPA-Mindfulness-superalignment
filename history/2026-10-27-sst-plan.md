# Optional SST optimizer experiment: design and implementation plan

Goal: implement the operator's PR 3 numerical optimizer-update transformation and a bounded retention probe, independently of canonical training admission. Binding specification: master prompt sections 3, 6, 18, 19 and 22. Base: `da84cb9298d2069fa195765fb13e7944e7da032a` (merged PR 804).

Architecture: `training/subspace_tuning.py` supplies a lazy-PyTorch, CPU-only adapter for explicitly named full-weight parameters owned by native SGD, Adam or AdamW. The optimizer receives unchanged gradients and updates its ordinary state. The adapter measures its actual parameter delta, applies the two-sided projector, and logs actual post-cast leakage. Fixed reference SVDs are the default; explicit refresh occurs after successful configured steps. Unsupported targets either raise before optimization or freeze with a diagnostic reason. Unsupported runtime modes fail closed.

Source: Chavan et al., arXiv:2610.22293v1, sections 2.1–2.3 and Appendix B.8 Algorithm 1, checked 2026-10-27. Paper license CC BY 4.0. No authoritative upstream code repository was identified; no upstream code is copied. Exact SVD in float64 replaces the paper's efficient Gram-based refresh. CPU-only rollback and resource bounds are repository adaptations, not published hyperparameters.

Approaches considered: changing the canonical backend would require checkpoint/configuration/distributed integration beyond this bounded stage; gradient hooks implement the wrong operation under Adam; an isolated applied-step adapter preserves existing paths and directly tests the published algorithm. The last approach is selected under the operator's instruction to proceed in manageable, disabled-by-default stages.

Constraints: default off; Python 3.10; no new dependencies; existing PyTorch extra only; exactly 17 canonical cases unchanged; no reward, verifier, constitutional, dataset or admission changes. Full-weight CPU float32/float64 only, dense unique nonaliased optimizer parameters, no closures, AMP, distributed, fused or differentiable steps. LoRA factor projection is not effective-weight SST and remains unsupported. Fixed-reference/model/optimizer/adapter checkpoints must be restored together; no silent resume through the canonical engine.

Review focus: Adam moments must see the full gradient; weight decay must be included in the measured delta; low-precision casting can reintroduce leakage; failures must restore all optimizer parameters and moments; a refreshed basis must not be described as preserving the initial subspace forever. Reject malformed or mismatched checkpoint state before mutation.
