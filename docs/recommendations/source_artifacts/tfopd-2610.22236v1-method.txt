Specialists share a base and architecture. Selected own-rollout teacher-forced layer inputs
provide G_d = X_d^T X_d / token_count. Prompt and answer positions contribute.
For each linear layer, D_d = W_d - W_base and
H_d = w_d [alpha G_d + (1-alpha) diag(G_d)].
W_fused = W_base + (sum_d D_d H_d) (sum_d H_d)^(-1).
The main configuration uses alpha=0.9, FP32 moment accumulation, FP64 solves and FP32 storage.
Other tensors use task arithmetic in the source; that portion is not implemented here.
Per-teacher unreproduced update energy is normalized by its base-update energy.
Selection excludes unfinished/repetition-loop answers and uses task grading where available.
The source uses a last-20000-character DEFLATE screen with ratio below 0.05.

GEPA implements bounded numeric proposals only, with source restrictions, explicit numerical
failures, log-scaled energy diagnostics and a documented UTF-8 screen adaptation.
No teacher/model runtime, verified outcome, checkpoint admission or empirical gain is supplied.
