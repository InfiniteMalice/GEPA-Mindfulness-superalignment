One autoregressive rollout emits a candidate set S. For common weight draws
w_k ~ Dir(1), its score is mean_k max_{y in S} dot(w_k, r(x,y)).
Use the SAME weight matrix for all compared sets from one prompt group.
Population-normalize rollout scores; the paper broadcasts the advantage over
the entire rollout. This note is not evidence of any GEPA behavioral improvement.
Official project https://vpo-rl.github.io/ links https://github.com/ryanboldi/vpo.

Upstream computes float64 products, stores float32 raw scores and zeros groups
with std < epsilon. GEPA retains binary64 metrics and reuses its population
std-plus-epsilon helper without that extra low-variance threshold.

bounded CPU preparation and all authority limits are Mindfulness adaptations.
