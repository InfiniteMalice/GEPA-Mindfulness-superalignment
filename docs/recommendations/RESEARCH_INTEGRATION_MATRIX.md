# Research-method applicability and integration matrix

The original October 2026 **proposal audit** was pinned to repository commit
`2ff430bb84ef81030918b48dba1fbd2c6a2cd336`. It does not change a recommendation,
reward or admission policy. Existing registries retain authority. On 2026-10-27, ActionOPD,
LoCD, SST, DeLoop, KnowGPO and PRM4RL sources were verified and experimental adapters/numerical kernels were added;
canonical training attachment and empirical transfer are unqualified. Other methods remain research leads.

The proposed primary path depends on PR 1's shared provenance/admission/accounting contracts.
Optional arms do not block stabilization. Dependency numbers refer to the operator's staged PR
plan; they are logical stages, not GitHub pull request numbers.

Compute estimates are deliberately workload-relative because checkpoints, task counts, budgets
and target hardware are not configured: **C0** = CPU record/contract checks, no model;
**C1** = C0 plus paired rollout/data experiments and any declared small-model training;
**C2** = C0 plus architecture, spectral, specialist or latent-model work requiring explicit
memory/FLOP estimates after model dimensions are known. Every row requires C0. No GPU hours,
teacher sampling counts, hyperparameters or API costs are inferred from an unavailable paper.

Paths below are relative to the named package unless qualified; `training/` means
`gepa_mindfulness/training/`, `verification/` means `gepa_mindfulness/verification/`.
ActionOPD/LoCD/SST/DeLoop/KnowGPO/PRM4RL adapter portions are **Experimental**; all other new runtime methods remain
**Unsupported** (planned, not implemented).

environment dependencies. The independently verified
knowledge-task milestone contract and protected credit-accounting layer are original
Mindfulness adaptations, not a robotics reproduction. No robotics stack is proposed as a core dependency.

The SST applied-update projection and refresh were verified against the primary v1 paper; the
bounded CPU adapter is not a full experimental reproduction. The potential-based shaping
subset was verified against PRM4RL; full training reproduction remains unsupported. LoCD + SST, constitution-filtered VPO, evidence-gated
teacher comparisons, text-only KTP, and advisory MPT are explicitly adaptation hypotheses.

LEV implementation. AGG geometry, SSOH orchestration and quantum-circuit code are outside scope.
